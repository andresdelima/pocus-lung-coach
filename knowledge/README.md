# Knowledge base

What the agents learn from. The agents are not fine-tuned. They read this material in their prompts, and every teaching claim must point back to a source here.

| Folder | What goes here | In the GitHub repo? |
|---|---|---|
| `educational/` | Original educational content written by the project author (slides, handouts, notes) | Only if the author chooses to publish it |
| `literature/` | Academic papers and guidelines (PDFs) | **No.** Usually copyrighted. Cited by reference only. |
| `view_cards/` | Short structured cards built from the two folders above, one per target view: expected structures, common errors, probe fixes, optimal settings, quality criteria, findings to teach, with source citations | Yes. This is what the agents actually load. |
| `notes/` | Page-cited notes on each paper, used to write the cards | No (paraphrased from copyrighted papers) |
| `sources.md` | List of every source with full citation | Yes |
